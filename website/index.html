EddyOS

Eine Linux-Distribution auf Arch-Basis: schnell wie CachyOS, zum Spielen bequem wie eine Konsole, im Alltag einfach wie Windows. Mit eigenem Design und ohne Terminal.

Vorschau ansehen Auf GitHub Roadmap
Gaming-PCOptimierter Kernel, Steam, Epic und GOG in einer Bibliothek.
Alter Mini-PCRetro-Konsole fürs Wohnzimmer, auch mit altem BIOS.
HandheldSteam Deck, ROG Ally, Legion Go und weitere.
UmsteigerDaten und Spiele von Windows einfach mitnehmen.

Stand: Konzeptphase. Die erste Live-ISO startet einen KDE-Plasma-Desktop, die EddyOS-Funktionen entstehen Schritt für Schritt.
